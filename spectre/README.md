# Spectre-syntax decks (not run here)

These decks mirror the ngspice testbenches generated by `analogic/` in Spectre
syntax, for use with a commercial PDK. They were **not simulated** in this
repository (no Spectre licence or FinFET/foundry models available), and the
`include` lines point at placeholder model files that you must replace with
your PDK's corner sections. All numbers in the top-level README come from the
ngspice flow, not from these decks.
